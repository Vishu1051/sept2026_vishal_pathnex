# scheduled pipelines
 
## jenkins pipeline - scheduled build
 you will learn  how to ** scheduled a jenkins pipeline using cron**.
 
 pipeline { 
     agent  any 
     enviroment {
         INSTITUTE_NAME = "Pathnex"
     }
     triggers {
          cron ('H 2 * * *') //everyday  at 2 am
     }
     stages {
        stage('checkout") {
           steps {
                git url: 'https://github.com/Pathnex/sample-java-app.git'
           }
       }
       stages('Build') {
             steps {
                 sh 'mvn clean package'
           }
        }
     } 
   }
